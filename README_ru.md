# Skrekkeparken

Интерактивная карта-игра, построенная на Leaflet и JSON-управляемых событиях. Игроки исследуют Brekkeparken (парк в Норвегии), выполняют задания и зарабатывают очки.

## 🎨 О Проекте

Skrekkeparken (Парк Ужасов) — это интерактивная карта-игра для мероприятия в Brekkeparken. Игроки перемещаются по реальной карте, находят маркеры с заданиями, отвечают на вопросы и зарабатывают "Skrekkepoeng" (очки ужаса). Команда с наибольшим количеством очков побеждает.

## ✨ Возможности

- **Интерактивная Карта Leaflet** — Реальная карта с кастомными маркерами
- **JSON-Управляемые События** — Задания загружаются из data/markers.json
- **Система Прогрессии на Очках** — Отслеживание очков команды
- **Геолокация** — Определение местоположения пользователя на карте
- **Темная/Светлая Тема** — Переключение режимов отображения
- **Боковая Панель Заданий** — Список выполненных заданий
- **Адаптивный Дизайн** — Работает на мобильных устройствах

## 🛠️ Технологии

- **Vanilla JavaScript** — Без фреймворков
- **Leaflet** — Библиотека интерактивных карт
- **HTML5** — Семантическая разметка
- **CSS3** — Кастомная стилизация с темами
- **JSON** — Хранение данных заданий

## 🚀 Начало Работы

Просто откройте `index.html` в браузере:

```bash
# Используя локальный сервер (рекомендуется)
npx serve .

# Или откройте напрямую
open index.html
```

## 🎯 Игровая Механика

1. **Интро-экран** — Приветствие и кнопка старта
2. **Карта** — Leaflet карта Brekkeparken с маркерами заданий
3. **Маркеры** — Клик по маркеру открывает задание
4. **Задания** — Вопросы с текстовым вводом ответа
5. **Очки** — Правильные ответы добавляют очки команде
6. **Боковая Панель** — Отслеживание выполненных заданий

## 🎯 Ключевые Функции

- **Геолокация** — Кнопка для центрирования карты на текущем местоположении
- **Переключение Тем** — Light/Dark режимы
- **Бургер-меню** — Мобильная навигация
- **Popup Заданий** — Модальное окно с вопросами
- **Система Очков** — Отслеживание и отображение Skrekkepoeng
