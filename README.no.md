# skrekkeparken

[English](README.md) · Norsk

Kartspill laget for et arrangement i Brekkeparken. Lagene går rundt i parken, finner markører, svarer på spørsmål og samler poeng.

Leaflet for kartet, oppgaver og markører kommer fra `data/markers.json` – ruten kan endres uten å røre koden. Reglene ligger på `rules.html`.

## Kjør

```bash
npx serve .
```

Geolokasjon fungerer bare på HTTPS eller localhost.
